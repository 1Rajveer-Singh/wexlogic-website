# WexLogic — Official Website

High-impact digital engineering, bespoke Next.js web applications, cinematic CGI/VFX campaigns, and scalable IT solutions.

## 🚀 Tech Stack
- **Framework**: Next.js 16 (Turbopack) & React
- **Design System**: Neobrutalist with curated Memphis aesthetics
- **Styling**: Vanilla CSS & TailwindCSS utilities
- **State Management**: Zustand
- **Database / ORM**: PostgreSQL & Prisma ORM

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### 3. Production Build
```bash
npm run build
npm start
```
